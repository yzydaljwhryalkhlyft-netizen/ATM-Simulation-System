# 🚀 Smart ATM System (Mobile-Optimized)

A clean, efficient, and robust Python script designed to simulate a real-world ATM application, fully optimized to run smoothly on mobile devices (like Pydroid 3) and computers alike.

## ✨ Key Features
* **🔒 Secure PIN Verification:** Simulates real card security with a maximum of 3 login attempts before locking the account.
* **💾 Persistent Data Storage:** Saves the user's balance automatically to a text file (`atm_data.txt`). Your balance remains safe even if you close the app!
* **💸 Full Transaction Suite:** Supports balance checking, dynamic cash deposits, and real-time withdrawals with simulated processing delays.
* **🛠️ Robust Error Handling:** Built with comprehensive input validation using `try-except` blocks to prevent crashes caused by unexpected user inputs.

## 🛠️ Technical Stack
* **Language:** Python 3.x
* **Core Concepts Used:** File I/O, Error Handling (Exceptions), Control Flow, Loops, and Functions.
* **Standards:** Written in clean code following PEP 8 guidelines with helpful comments.

## 📱 How to Run on Mobile
1. Download **Pydroid 3** from the Google Play Store.
2. Copy the `atm_system.py` code into the app.
3. Press the **Play** button and start interacting!
